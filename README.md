## Projects

### [Payment Orchestration Engine](https://payment-orchestration-engine-system.pages.dev/)

A multi-gateway payment routing and orchestration service that unifies **Razorpay and Cashfree** behind a single API. It supports dynamic gateway routing and automatic fallback, along with idempotent payment processing, secure webhook verification, duplicate webhook protection, and payment event audit logging.

**Stack:** Node.js · Express.js · TypeScript · PostgreSQL · Drizzle ORM · Docker

### [eKart](https://ekart-system.pages.dev/)

A full-stack e-commerce platform with a microservices-based architecture, providing **product catalog, cart, order management, and inventory tracking**. It uses Redis for caching and rate limiting, integrates the Payment Orchestration Engine for multi-gateway payments, and uses BullMQ for asynchronous email notifications.

**Stack:** React · Node.js · Express.js · MongoDB · Redis · Docker · BullMQ · Cloudinary

### [Mock API AI](https://mock-api-ai-system.pages.dev/)

An LLM-powered mock REST API generator with **runtime validation and CRUD support**, built to generate APIs dynamically from natural language input.

**Stack:** Node.js · TypeScript · PostgreSQL · Drizzle ORM · Groq API
